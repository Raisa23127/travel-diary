# travel-diary
# 🌍 Дневник Путешественника

Веб-приложение для ведения личного дневника путешествий 
с визуализацией на карте, статистикой и фотографиями.

---

## 📖 О проекте

Приложение позволяет вести дневник поездок: добавлять города 
и страны, отмечать места на интерактивной карте, прикреплять 
фотографии, ставить оценки и смотреть статистику путешествий.

**Учебный проект** по производственной практике.  
Тема: «Разработка веб-приложения для ведения дневника 
путешественника с визуализацией посещённых мест на карте 
и статистикой поездок».

---

## ✨ Возможности

- 🔐 **Авторизация** — регистрация, вход, выход; пароль 
  хэшируется через SHA-256
- ✈️ **Поездки** — добавление, редактирование, удаление
- 🗺️ **Карта** — Leaflet + Яндекс.Карты, нумерованные маркеры, 
  маршрут между точками
- 📍 **Выбор точки** — кликом по карте, координаты 
  подставляются в форму
- 📷 **Фотографии** — загрузка с автосжатием до 1200 px, 
  просмотр в лайтбоксе
- 📊 **Статистика** — количество поездок, городов, стран, 
  дней, километров
- 🔍 **Поиск и фильтры** — по названию, стране, городу, оценке
- 🎨 **Темы** — светлая и тёмная
- 📤 **Экспорт** — в JSON и CSV
- 📥 **Импорт** — из JSON
