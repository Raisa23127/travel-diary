## Трудности и решения

### Проблема 1. Разделение `app.js` на модули

При выносе кода в отдельные файлы нарушился порядок загрузки 
скриптов. Функции вызывались раньше, чем модули были загружены.

**Решение:** в `index.html` модули подключаются **до** `app.js`, 
в порядке зависимостей: `auth.js` → `photos.js` → `map.js` → `app.js`.

### Проблема 2. Хэширование пароля

Изначально пароли хранились в открытом виде, что небезопасно.

**Решение:** изучен Web Crypto API, реализовано хэширование 
через `crypto.subtle.digest('SHA-256', ...)` с солью.

### Проблема 3. Ограничение localStorage

Фотографии в base64 быстро заполняли хранилище (лимит ~5 МБ).

**Решение:** добавлено автосжатие через HTML Canvas до 1200 px 
по большей стороне, качество JPEG 80%.
